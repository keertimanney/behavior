# BEHAVIOR episode walkthrough

Interactive research walkthrough of Astra's hanging_pictures episode f316a723-8f24-4ea5-a99e-7d32eeca6784.

This repository contains the static assets of the published viewer: HTML, CSS, JavaScript, the original rollout video, observations and prepared trace records. It can be served directly, without a framework or build step.

Public viewer: https://keertimanney.github.io/behavior/

Source records remain linked from the interactive charts. Evaluator measurements are distinguished from agent observations; this is a case study of one rollout.
